Mais Facil — Meshtastic LoRa Mesh

Rede mesh criptografada. Sem internet, sem torre, sem assinatura. Plug-and-play.

R$100 — R$150/no Facil 2-20 km/hop

💡 O que e

Meshtastic e firmware open-source que transforma modulos LoRa em nos de rede mesh. Cada no e simultaneamente receptor, transmissor e repetidor. Funciona com bateria 18650 ou solar.

🔍 Metodo de Uso

  • 🔧
    Flashear firmware: Acesse flasher.meshtastic.org (Chrome/Edge). Conecte via USB. Selecione seu modelo. Clique "Flash".
  • 🌐
    Configurar regiao: US (915 MHz) para Americas, EU_868 para Europa. Configure canal criptografado (PSK/AES-256).
  • 📱
    App celular: Android/iOS: app Meshtastic na loja. Conecte via Bluetooth. Envie mensagem de teste.
  • 🔗
    Dashboard: Use MeshWX para transmitir alertas NWS pelo mesh e injetar no dashboard via WebSocket.
✅ Custo para rede familiar (4 nos) 4x Heltec LoRa 32 = ~R$500 total. Sem mensalidade. Funciona em desastres, hiking, camping, interrupcoes de rede.

Melhor Custo-Beneficio — RTL-SDR + NOAA Weather Radio

Receptor de alertas meteorologicos 24/7 via radio VHF. Detecta automaticamente alertas SAME/EAS.

R$200 — R$350 Intermediario 50-100 km

💡 O que voce recebe

O NOAA Weather Radio (NWR) transmite 24/7 em 7 frequencias VHF (162.400 — 162.550 MHz) nos EUA. Cada transmissao inclui codigos SAME que identificam tipo de alerta, area afetada e duracao. No Brasil, a REDENET/INMET opera em FM/AM.

🌡 Antena DIY — Dipole VHF 162.5 MHz

Material Necessario

  • 2x fio de cobre 14 AWG — comprimento: 46.15 cm cada
  • 1x cabo coaxial RG-58 — max 5m
  • 1x conector F femea — para soldar no cabo
  • Suporte de plastico ou madeira — para manter angulo

Calculo:

Formula: Comprimento = (300 / frequencia_MHz) / 4 Calculo: 300 / 162.5 / 4 = 0.4615m = 46.15 cm por elemento Total meia-onda: 46.15 x 2 = 92.3 cm Ajuste: +/- 5% para ressonancia ideal (43.8 a 48.5 cm)

Montagem:

Vista superior (angulo: 90-120 graus): Elemento A (46cm) / / / Centro ───── <-- Cabo coaxial (para o SDR) \ \ \ Elemento B (46cm)
  • Monte no minimo 3m acima do solo
  • Posicione longe de metal — telhados, canos interferem
  • Use cabo curto — cada metro perde ~0.3dB
  • Orientacao: vertical para NWR (polarizacao vertical)
💡 Projeto recomendado: NWS-Alert-Dashboard github.com/robwolff3/NWS-Alert-Dashboard — Docker container unico com 3 fontes: NWWS-OI (XMPP push), NOAA Weather Radio (RTL-SDR), e weather.gov API. Deduplicacao automatica.

Imagens de Satelite — NOAA APT

Imagens meteorologicas diretamente de satelites NOAA. Passagens de 10-15 min, 2-4x por dia.

R$200 — R$400 Intermediario Orbital (global)

💡 O que voce recebe

NOAA-15 e NOAA-19 transmetem imagens APT (Automatic Picture Transmission) em 137 MHz. Cada passagem dura ~10-15 minutos e produce uma imagem strip do terreno em infravermelho e visivel.

⚠️ NOAA-18 desativado Em junho de 2025, a NOAA desativou NOAA-18. APT permanece ativo em NOAA-15 e NOAA-19.

Avancado — GOES Satelite (L-Band)

Imagens de alta resolucao e dados EMWIN do satelite geoestacionario. Antena fixa apontada uma vez.

R$500 — R$900 Avancado Cobertura continental

💡 O que voce recebe

GOES-East (GOES-16/19) e GOES-West (GOES-17/18) transmetem em 1694.1 MHz (L-Band):

  • Imagens full-disk: infravermelho e visivel, a cada 10-15 minutos
  • Dados EMWIN: Emergency Managers Weather Information Network
  • Alertas: furacoes, tornados, enchentes

🌡 Alinhamento da Antena

  • 📍
    Descobrir posicao do GOES: Acesse agsattrack.com ou n2yo.com. Insira suas coordenadas. Anote azimuth (bussola) e elevation (angulo vertical).
  • 🧭
    Bussola analoga: Nao use celular (erro 20-30 graus). Compre bussola analoga (R$15).
  • 📈
    Monitorar Viterbi Error Rate: Rode goesrecv -v -i 1 -c goesrecv.conf. Valor < 100 = otimo. > 2000 = sem sinal.
💡 Alternativa: SatDump SatDump e mais completo que goestools. Suporta GOES, Meteor, FY-4A. Interface grafica.
💡 Dica: Modificar grade WiFi 2.4GHz Grade WiFi de 2.4GHz (~R$150) funciona em 1.7GHz para GOES. Remova feed 5GHz, instale dipole/helix 1.7GHz no ponto focal.

Alcance Global — HF Shortwave

Recepcao global via ionosfera. NAVTEX, emergencia maritima, alertas de qualquer continente.

R$300 — R$500 Intermediario Global (1000+ km)

💡 O que voce recebe

Ondas curtas (HF, 3-30 MHz) viajam globalmente refletidas pela ionosfera:

  • NAVTEX (518/490 kHz): navegacao + meteorologia maritima
  • EPIRB (2182 kHz): emergencia maritima internacional
  • WEFAX: imagens meteorologicas por radio
  • WWV (5/10/15 MHz): hora precisa + alertas NWS

🔨 Hardware

📡
RTL-SDR + Upconverter
Necessario upconverter (Ham It Up v2) para receber HF. IF output: 125MHz.
R$200 — R$350
rtl-sdr.com • nooelec.com (Ham It Up)

R$10 — R$50 (DIY)
Material: fio de cobre, isolador, cabo coaxial
📱
PC ou Raspberry Pi
SDR software: SDR#, GQRX, SDR++. PC funciona melhor que Pi para HF.
R$250+
raspberrypi.com • Qualquer PC Linux/Windows

Melhora rejeicao de RFI (interferencia de rede eletrica).
